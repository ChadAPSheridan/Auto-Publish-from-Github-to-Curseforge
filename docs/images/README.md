This directory contains screenshots and images referenced in the main README walkthrough.

## Required Screenshots

The following screenshots should be added to this directory to complete the walkthrough:

**Purpose**: Show users how to generate an API token in the CurseForge Console
**Content**: Screenshot of the CurseForge Console showing the API token generation interface
**Steps to capture**:
- Navigate to https://console.curseforge.com/
- Show the "Generate API Token" button or API Tokens section
- Highlight the token creation interface

### 2. `github-secrets.png`
**Purpose**: Show users how to add secrets to their GitHub repository
**Content**: Screenshot of the GitHub repository settings showing the Secrets configuration
**Steps to capture**:
- Go to repository Settings → Secrets and variables → Actions
- Show the "New repository secret" interface
- Display the form where users enter the secret name and value

### 3. `curseforge-project-id.png`
**Purpose**: Help users locate their CurseForge project ID
**Content**: Screenshot showing where to find the project ID on CurseForge
**Steps to capture**:
- Navigate to a CurseForge project page

### 4. `github-release.png`
**Purpose**: Show users how to create a new release on GitHub
**Content**: Screenshot of the GitHub release creation interface
**Steps to capture**:
- Navigate to the Releases section of a GitHub repository

### 5. `github-actions.png`
**Purpose**: Show users how to monitor their workflow execution
**Content**: Screenshot of the GitHub Actions tab showing a running or completed workflow

- Navigate to the Actions tab of a GitHub repository

## Image Guidelines

When adding screenshots:
- Use PNG format for best quality
- Capture at a reasonable resolution (1920x1080 or similar)
- Ensure any sensitive information (API tokens, personal data) is redacted
- Use browser screenshot tools or tools like:
  - macOS: Cmd+Shift+4
  - Windows: Windows+Shift+S
  - Linux: gnome-screenshot or similar
- Consider adding annotations (arrows, highlights) to draw attention to key elements
- Keep file sizes reasonable (compress if needed)

## Alternative: Using Placeholder Images

If you don't have access to create these screenshots, you can:
1. Create simple placeholder images with text indicating what should be shown
2. Link to external documentation that includes relevant screenshots
3. Use diagrams or illustrations instead of screenshots

## Tools for Creating Screenshots

- **Browser Extensions**: Awesome Screenshot, Nimbus Screenshot
- **Desktop Tools**: Snagit, Greenshot, ShareX
- **Online Tools**: Markup.io, Skitch
- **Annotation Tools**: To add arrows and highlights after capturing
